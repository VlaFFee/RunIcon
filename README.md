# Run Icon (Minecraft 1.20.1, Forge 47.2.0+)

Клиентский мод: пока игрок бежит (спринт), в правом нижнем углу экрана
плавно появляется анимированная пиксельная иконка бега. Когда игрок
останавливается — плавно исчезает. При скрытом HUD (F1) не показывается.

## Сборка
Нужен JDK 17 и Gradle (или Gradle wrapper от Forge MDK 1.20.1).

1. Скачайте Forge MDK 1.20.1 (47.2.0+) с https://files.minecraftforge.net/ и возьмите
   из него папку `gradle/` и файлы `gradlew`, `gradlew.bat` — положите в корень этого проекта.
2. `./gradlew build`
3. Готовый мод: `build/libs/runicon-1.20.1-1.0.0.jar` — положить в папку `mods`.

Для запуска из среды разработки: `./gradlew runClient`.

## Своя иконка
Текстуры: `src/main/resources/assets/runicon/textures/gui/run_icon.png` (бег) и `swim_icon.png` (плавание)
Формат: вертикальная лента из 4 кадров по 16x16 пикселей (итого 16x64), прозрачный фон.
Если поменяете число кадров или размер, правьте константы в `RunIconOverlay.java`.

## Настройки в коде (RunIconOverlay.java)
- `DRAW_SIZE` — размер иконки на экране (по умолчанию 32)
- `MARGIN` — отступ от краёв
- `RUN_FRAME_MS` / `SWIM_FRAME_MS` — скорость анимации бега и плавания

## Сборка без установки Java/Gradle (через GitHub)
1. Создайте пустой репозиторий на github.com и загрузите в него все файлы проекта
   (включая папку `.github`).
2. Откройте вкладку **Actions** → дождитесь зелёной галочки у workflow "Build mod"
   (или запустите вручную: Run workflow).
3. Откройте завершённый запуск → внизу в **Artifacts** скачайте `runicon-jar`.
   Внутри будет `runicon-1.20.1-1.0.0.jar` — его и кладите в папку `mods`.
